# Spring 2026 Capstone: [Your Game Title Here]

## Project Overview
This is a philosophical game project developed for the **Games for Learning** program at **NYU**. The project explores themes of **existentialism, ethics, and constructivism** through an interactive narrative.

## Tech Stack
* **Language**: Python
* **Editor**: Visual Studio Code
* **Version Control**: Git & GitHub
* **Target Platforms**: Windows, macOS, and Steam Deck

## Features
* Philosophical fairy tale narrative.
* Visual novel style interaction.
* AI-driven tutor/advisor systems (integrated using tools like n8n and Supabase).

## How to Run.
1. Ensure you have **Python 3.10+** installed.
2. Clone this repository: 
   `git clone https://github.com/dk4991/spring2026_capstone.git`
3. Install dependencies:
   `pip install -r requirements.txt`
4. Run the game:
   `python main.py`
